# autoBattler

An idle dungeon crawler for Windows: a fusion of Diablo 2 and Clickpocalypse II, as creative inspiration. See the [game design](docs/design.md).

```bash
npm install
npm run dev
```

`npm run dev:electron` runs the desktop version. Working on the code, or pointing an AI agent at it? Start with [AGENTS.md](AGENTS.md).
